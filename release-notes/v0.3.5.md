# Drive Storage Card 0.3.5

Patch release for reliable discovery of current UniFi Drive integration
entities.

## Highlights

- Recognizes the current restart and remote backup action translation keys.
- Uses authoritative integration translation keys before legacy entity-ID
  fallbacks, avoiding collisions between similarly named dynamic entities.
- Adds a complete integration contract test across aggregate storage, pools,
  drives, snapshots, backups and updates.

## Validation

- TypeScript typecheck, ESLint, Vitest and Vite build.
- Browser render smoke test.
- HACS/custom-card compatibility, license and release metadata checks.
- Local anonymization check and production dependency security audit.
