# Drive Storage Card 0.3.4

Patch release with current Home Assistant frontend compatibility and visual
polish.

## Highlights

- Updated the visual editor to use current Home Assistant input components.
- The card picker now suggests a correctly device-scoped Drive Storage Card
  for compatible UniFi Drive entities and links directly to the documentation.
- Improved metric and sensor-row typography for clearer values and a more
  native Home Assistant appearance.
- Added Sections View sizing support for predictable placement in modern
  dashboards.

## Validation

- TypeScript typecheck, ESLint, Vitest and Vite build.
- Browser render smoke test.
- HACS/custom-card compatibility, license and release metadata checks.
- Local and GitHub-surface anonymization checks.
- Production dependency security audit.
