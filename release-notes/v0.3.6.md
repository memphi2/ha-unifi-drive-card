# Unifi Drive / UNAS Card 0.3.6

Marketplace readiness and maintenance release for current Home Assistant
dashboard installations.

## Highlights

- Renamed the Marketplace and visual-editor display name to
  **Unifi Drive / UNAS Card**.
- Added direct Home Assistant Marketplace installation links and documentation
  for automatic resource versioning after updates.
- Added a contract fixture from the current UniFi Drive integration to protect
  entity discovery and dynamic pool, drive, snapshot and backup grouping.
- Updated the CI/test toolchain and added locked dependency auditing, pinned
  GitHub Actions and Dependabot security updates.
- Updated the locked transitive `undici` dependency to the current patched
  version.
- Cancels pending gestures when card settings change, preventing an old tap or
  hold from running a newly configured action.
- Preserves empty section selections and updates dynamic groups when their
  integration attributes change. Pending service locks survive overlapping
  calls across reconnects.
- Separates read-only release validation from publication and adds quarterly
  grouped dependency maintenance with independent security updates.
- Keeps explicit entity selections when an entity is missing instead of silently
  choosing another control, and uses registry semantics ahead of renamed IDs.
- Refreshes cached values and labels when HA formatting helpers change and
  shares discovery state projections across multiple cards.
- Makes editor help usable with touch and keyboard and keeps switch labels
  clickable without letting help buttons change settings.

## Validation

- TypeScript typecheck, ESLint, Vitest and Vite build.
- Browser render smoke test.
- HACS/Marketplace packaging compatibility, license and anonymization checks.
- Full locked dependency audit with no findings.
- Original HA 2026.4.0 and 2026.11.0 components: card rendering, visual-editor name
  input, switch labels, keyboard controls and mobile/desktop help tooltips.
- Release archive contents compared with the generated build.
